# The Exhibit Discovery & Memory Paradox

**Status**: [DISCUSSION_ARCHIVE]
**Topic**: Collective Resonance vs. Fragmented Memory in IP Manifestation.

## 1. Current Implementation (The Hierarchy)

In the `shimokitan` ledger, we use a three-tier structure to organize cultural work:

*   **Work (IP Anchor)**: The Master Franchise/Idea (e.g., *Genshin Impact*). 
    *   *Purpose*: The umbrella that groups all products, sequels, and spinoffs.
*   **Artifact (The Registry)**: The Canonical Manifestation (e.g., *Genshin Impact Global Game*).
    *   *Purpose*: The central unit of **Resonance** (Heat Score) and **Zines** (Permanent Memories).
*   **Exhibit (The Immersion)**: The Media Layer (e.g., *Version 4.0 Trailer*, *Opening Movie*).
    *   *Purpose*: The visual/experiential layer nested *within* an artifact.

## 2. Identified Problems

### I. The "Memory Lock" (Zine Fragmentation)
Zines represent a **Permanent Memory** of an encounter. In the current architecture, a Zine is unique to the `(Artifact, Author)` pair. 
*   **The Issue**: If a user writes a Zine for the *Genshin Global Game*, they have "spent" their memory slot for that artifact. 
*   **The Paradox**: When the *Version 4.2 Trailer* (Exhibit) is added, the user has a **New Memory** for this specific cinematic experience, but they are **locked out** of recording it because they already have a Zine for the parent Artifact. Memory cannot be edited; it can only be added.

### II. The Discovery Gap (The "Buried" Exhibit)
Discovery is currently **Registry-First**, but user behavior is typically **Media-First**.
*   **The Issue**: Exhibits are not "Featured" in the search results or Home Page spotlight. They stay "hidden" inside the Artifact Detail page.
*   **The Paradox**: If a high-energy trailer is "just an Exhibit," it loses its ability to drive traffic from the Home Page. If we make it an *Artifact* (to feature it), we fragment the Resonance score of the game.

### III. The Heat Crisis (Resonance Fragmentation)
User energy (Sparks/Reactions) is currently tied to individual Artifact IDs.
*   **The Issue**: Splitting a game's resonance across its trailers, spinoffs, and promotional artifacts prevents a single "Center of Gravity" for the community.
*   **The High-Contrast Goal**: We want a Work to feel "Massive" through collective heat, but we want the Discovery of that heat to start with the latest "Fresh" media (the Exhibit).

## 3. Conceptual Goals & Insights

We aim for **"Collective Resonance with Contextual Immersion."**

### I. Immutable Contextual Memories
Instead of one Zine per Artifact, we should support **Exhibits receiving their own Zine slots** while still contributing resonance to the **Parent Artifact**.
*   *Insight*: A user should be able to record a memory of the *Game* AND a memory of a *specific Trailer* as separate, permanent shards of their life as a district resident. Both shards contribute to the game's total Heat Score.

### II. Resonant Discovery (The Media Bridge)
Exhibits must become **Discoverable Entry Points** without becoming **Registry Entries**.
*   *Insight*: The Home Page should be able to feature a "Featured Exhibit" (The New Trailer). Clicking it launches the user into the **Artifact Detail Layer**, but with the focus immediately set on that Exhibit.

### III. Professional Registry Logic
Maintain a high-contrast distinction between **Cataloging (Artifacts)** and **Experiencing (Exhibits)**.
*   *Insight*: The Archives (Browser) should only list high-level, canonical items. If the catalog is cluttered with 50 trailers for one game, it fails the "Professional Ledger" standard. Exhibits are the **Gallery** of the record, not the record itself.
*   *Verdict*: One Work can have many Artifacts (Original vs. Cover), but one Artifact should house its own "Immersion Timeline" via Exhibits.

**Core Tenet**: *Resonance is collective; Encounter is individual; Memory is permanent.*
